⚽ FIFA World Cup 2022 Exploratory Data Analysis (EDA)

📌 Overview

This project performs a comprehensive Exploratory Data Analysis (EDA) on the FIFA World Cup 2022 dataset. Using Python and data visualization libraries, the project explores team performance, player statistics, club-wise player distribution, kit sponsors, and various football performance metrics to uncover meaningful insights from the tournament.

---

🚀 Features

- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Team Performance Analysis
- Player Statistics Analysis
- Club-wise Player Distribution
- Kit Sponsor Analysis
- Goals, Assists, and Saves Analysis
- Per-90 Performance Metrics
- Interactive and Informative Visualizations

---

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

📂 Dataset

The dataset includes detailed information about the FIFA World Cup 2022, including:

- Teams
- Players
- Football Clubs
- Player Positions
- Goals
- Assists
- Saves
- Minutes Played
- Per-90 Statistics
- Team Kit Sponsors
- Tournament Performance Metrics

---

📊 Analysis Performed

- Team-wise performance comparison
- Club-wise player representation
- Kit sponsor distribution across national teams
- Top goal scorers and assist providers
- Goalkeeper saves analysis
- Per-90 performance metrics
- Position-wise player distribution
- Tournament trends and statistical insights
- Correlation analysis between football statistics

---

📈 Key Insights

- Identified the clubs contributing the most players to the tournament.
- Compared team performance using multiple statistical metrics.
- Analyzed player efficiency through per-90 statistics.
- Explored relationships between goals, assists, saves, and overall performance.
- Visualized tournament trends using informative charts and graphs.
